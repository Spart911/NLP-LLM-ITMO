# NLP & LLM ITMO

Интерфейс к каталогу товаров. Человек пишет обычную фразу, модель превращает ее в параметры, а товары читает обычный код из SQLite.

## Состав

`lab1/catalog` — сама программа.

- `config.py` и `llm.py` читают ключ, адрес провайдера и имя модели только из окружения.
- `schema.py` описывает параметры поиска: категория, потолок цены, порядок сортировки.
- `prompts.py` собирает сообщения для модели.
- `db.py` и `search.py` держат каталог: 24 товара с названием, брендом, категорией, ценой и остатком.
- `flows/` — сценарии: классификация, разбор параметров, поиск, повтор с журналом, уточнения диалога.
- `report.md` — отчет по прогонам и ответы на контрольные вопросы. В интерфейсе он открывается пунктом «Отчет».
- `ui.py` открывает страницу, на которой сценарий выбирается и запускается.

Прогоны пишутся в `lab1/results`.

## Настройка

Нужен Python 3.12.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r lab1/requirements.txt
```

Секреты и адрес провайдера в код не записываются. Рабочие значения лежат в `.env` в корне репозитория, файл в git не попадает. Имена переменных:

- `LLM_API_KEY`
- `LLM_BASE_URL`
- `LLM_MODEL`

Пустой образец — `.env.example`.

## Запуск

Из каталога `lab1`:

```bash
python -m catalog
python -m unittest discover -s tests
```

Без аргументов открывается страница на `http://127.0.0.1:8765`. Отдельный сценарий запускается по имени:

```bash
python -m catalog classify
python -m catalog interpret
python -m catalog lookup
python -m catalog recovery
python -m catalog dialogue
```
